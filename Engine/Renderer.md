# Renderer

**Source:** `src/renderer.h`, `src/renderer.cpp`

Owns graphics pipelines, vertex/index buffers, and records all scene draw commands. Stateless about the scene itself — receives `SceneObject` array from the [[Main Loop]] every frame.

## Depends on

- [[Vulkan Context]] — `VkCtx` handle struct, `vk_check`, `vk_find_memory_type`; uses `device`, `render_pass`, `swapchain_extent`
- [[Shaders]] — embedded SPIR-V headers `vert_spv.h` / `frag_spv.h` generated by the [[Build System]]; mirrors the push-constant layout defined there

## Used by

- [[Main Loop]] — only caller

## Key data

- `SceneObject` — name, `ShapeType` (cube/sphere/pyramid/cylinder), position, euler rotation, uniform scale, `tex_mode`
- `Vertex` — 11 floats: position, color, normal, UV
- Two pipelines: fill (back-face cull) and wireframe (no cull), both with dynamic viewport/scissor
- Push constants: vertex stage 0–127 (`mvp` + `model`), fragment stage 128–191 (`FragPC` lighting block)
- Dynamic buffers (vertex/index/sky/gizmo) are duplicated per in-flight frame and persistently mapped — CPU writes frame N while the GPU may still read frame N-1
- `renderer_draw` records each object's buffer offsets into `draws[]`; `renderer_draw_outline` reuses those offsets instead of re-uploading

## Draw passes (per frame, in order)

1. Sky fullscreen triangle (gradient mode 1 or atmosphere mode 5) when `bg_mode > 0`
2. Scene objects — each shape tessellated by `make_shape`, uploaded to shared host-visible buffers, drawn with per-object push constants (`tex_mode` packed as `render_mode + tex_mode * 16`)
3. Planar projected shadows (mode 6) when in Rendered mode
4. Ground grid quad (mode 3)
5. Selection outline (scaled wireframe, mode 4) and translate/scale/rotate gizmo — called separately by [[Main Loop]]

## Known issues

- Full scene re-tessellated and re-uploaded every frame; only 4 shape types exist, should be cached
- No bounds check on vertex/index cursors against buffer capacity
